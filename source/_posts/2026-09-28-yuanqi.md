9月27日晚上，我决定用 Hexo + GitHub Pages 创建个人博客。我让豆包提供了一份《 Hexo + GitHub Pages 搭建个人博客完整教程》，一边看教程，一边操作。因为下载速度太慢，临睡前我只安装了 Node.js 和 Git。

9月28日早上，我利用工作间隙注册了 GitHub 账号并创建站点仓库，安装了Hexo，最后把网站部署到 GitHub Pages。中午，我让豆包给我推荐了5款适合新手的 Hexo 主题，我看了介绍之后选择了ils，因为 I Like Simple。安装了 ils 之后，我发现首页的文章只显示摘要，点击文章标题和阅读全文都会跳转到空页面，但在 source\\_posts 里有文章对应的 md 文件。我问豆包该如何设置才能看到整篇文章，我按它的提示操作也没有解决问题。我正准备放弃努力时，无意中发现使用 hexo deploy 命令后，出现了一些报错提示。豆包告诉我这是主题依赖的字数统计插件缺失导致的模板渲染报错，关闭字数统计功能就能解决。我试过之后，惊喜地发现一直困扰我的问题也解决了。做完这一切，一天即将过去。写下这段文字记录这全情投入的一天。

10月3日下午，回顾了这几天研究 ils 主题的经过，主要解决了三个问题：1.首页只显示文章摘要，点击阅读全文会跳转到空页面。2.博客文章没有首行缩进。3.新建的分类页和标签页点开后是空页面。前两个问题是豆包帮我解决的，第三个问题先问了豆包，没能解决，最后是在千问的协助下解决的。晚上十点半，安装新主题 keep 并开始设置，到一点钟，基本设置好，花了两个半小时，出乎我的意料。

10月5日上午，在千问的帮助下，通过在 Keep 主题中注入自定义的 CSS 解决博客文章没有首行缩进的问题。目前，自定义配置多个作者标识还没解决。

10月6日上午，把昨天晚上用 workbuddy 转换的 svg 图标上传到博客，替换原来的 png 图标，虽然没有原生 svg 图标小，但体积也只有原先图标的三分之一。

10月7日晚上九点，在豆包的指导下，我开始把博客源码推送到 GitHub 仓库的 main 分支，到凌晨一点半才成功，真是不容易。

10月13日下午，我发现写文章时明明用的是中文全角标点，用电脑浏览器打开博客看到的却是英文半角标点，用手机浏览器看没问题。先问了豆包，没能解决。晚上又去找千问，它得出结论：字符本身是对的，桌面浏览器给它套了一个“窄版字形”的字体，这是纯前端渲染问题。最后在 custom.css 中加一段代码，问题解决。

10月16日下午，在豆包的帮助下，在 custom.css 中加入代码 --base-font-size: 16px 把网页全局基础字体大小由默认的 15.2px 改为 16px。晚上，询问豆包，想解决自定义配置多个作者标识失败的问题，结果毫无悬念的失败了。卸载了默认主题 landscape。

10月17日上午，卸载了 hexo-generator-searchdb（本地搜索插件），因为 Keep 主题已经内置搜索功能。安装 hexo-generator-feed（RSS订阅插件）。

10月20日，继续研究 keep 主题内置的 CSS 变量，把全局基础字体大小改为 18px。

10月21日，卸载 hexo-generator-index-pin-top（文章置顶插件）。Hexo 官方首页生成器（hexo-generator-index）版本 ≥ 4.0，就原生支持 sticky，不需要任何额外插件。在文章的 Front Matter 中添加 sticky 属性，即可实现在 Home（首页）置顶该文章。sticky 值越大，置顶越靠前。

10月23日下午四点，开始向豆包咨询图床的相关问题。晚上，创建相册页面，使用 PicX 上传5张风景照，没有压缩，也没有用 CDN 加速，网页打开速度很慢。到凌晨1点才基本弄好。

10月24日上午，删掉之前上传的5张风景照，通过 PicX 压缩后上传9张风景照到新建的 GitHub 仓库，用了 jsDelivr CDN 加速，访问速度还不错。到中午全部弄好。

10月26日上午，把 PicX 的登录方式由填写 GitHub Token 登录改为 GitHub OAuth 授权登录，并删除了 GitHub Token。

10月27日下午，把相册的图片全部删掉，把图片压缩成 webp 格式后重新上传。晚上，把作者头像和网站 logo 都换成 webp 格式，体积缩小到原来的四分之一。回望这充实的一个月，收获颇多。

**附：遇到的问题及解决办法**

**问题一：首页只显示文章摘要，点击阅读全文会跳转到空页面。**

解决办法：1.修改_config.yml
```yaml
url: https://arvincolin.github.io/
root: /
permalink: :abbrlink/   # 这个是安装了插件hexo-abbrlink后改的
```
2.修改_config.ils.yml
```yaml
post_wordcount:
  wordcount: false   # 关闭字数统计
  min2read: false    # 关闭阅读时长统计
# 安装了插件hexo-wordcount后，改为true
```
**问题二:博客文章没有首行缩进。**

解决办法：打开 themes/ils/source/css/style.styl 在最后添加下面的代码
```css
/* 文章正文段落首行缩进2个汉字 */
.article-content p
  text-indent 2em
  text-align justify
# 后来，为了第一段也有首行缩进，删掉了下面三行
/* 可选：标题后的第一段不缩进，符合中文出版规范 */
.article-content p:first-of-type
  text-indent 0
```
**问题三：新建的分类页和标签页点开后是空页面。**

解决办法：第一步 在themes\ils\layout\page.ejs里补两个分支
```html
   <% } else if (is_tag()) { %>
                    <%- partial('tag-content') %>

                <% } else if (page.type === 'categories') { %>
                    <%- partial('_partial/all-categories') %>

                <% } else if (page.type === 'tags') { %>
                    <%- partial('_partial/all-tags') %>

                <% } else if (page.title == 'about') { %>
```
第二步：新建themes\ils\layout\_partial\all-categories.ejs
```html
<div class="fade-in-down-animation">
  <div class="category-container">
    <div class="category-name">
      <i class="fa fa-folder"></i> 全部分类 [<%= site.categories.length %>]
    </div>
    <ul class="category-list">
      <% site.categories.sort('name').each(function(cat){ %>
        <li>
          <a href="<%- url_for(cat.path) %>"><i class="fa fa-folder-o"></i> <%= cat.name %></a>
          <span class="category-list-count">[<%= cat.length %>]</span>
        </li>
      <% }) %>
    </ul>
  </div>
</div>
```
第三步：新建新建themes\ils\layout\_partial\all-tags.ejs
```html
<div class="fade-in-down-animation">
  <div class="tag-container">
    <div class="tag-name">
      <i class="fa fa-tag"></i> 全部标签 [<%= site.tags.length %>]
    </div>
    <div class="tag-cloud">
      <%- tagcloud({
        min_font: 13, max_font: 26, amount: 300,
        color: true, start_color: '#999', end_color: '#111',
        orderby: 'name', order: 1
      }) %>
    </div>
  </div>
</div>
```
第四步：在themes\ils\source\css\style.styl里加入下面的代码
```css
.category-list { list-style: none; padding: 0; margin: 16px 0 0 0; }
.category-list li { margin: 10px 0; padding-bottom: 8px; border-bottom: 1px dashed #eee; }
.category-list li a { text-decoration: none; }
.category-list li a:hover { color: #409eff; }
.category-list-count { margin-left: 8px; opacity: .5; font-size: .9em; }
.tag-cloud { margin-top: 16px; line-height: 2; }
.tag-cloud a { display: inline-block; margin: 4px 10px; text-decoration: none; }
```
**问题四：博客文章没有首行缩进。**

解决办法：第一步 用下面的代码替换_config.keep.yml里的inject部分
```yaml
# ---------------------------------------------------------------------------------------
# Docs: https:inject.html
# ---------------------------------------------------------------------------------------
inject:        
  enable: true   # Option values: true | false
  css:
    - /css/custom.css
    # e.g.
    # - /css/custom-1.css
    # - /css/custom-2.css
    # - ...
  js:
    -
    # e.g.
    # - /js/custom-1.js
    # - /js/custom-2.js
    # - ...
```
第二步：新建source/css/custom.css，写入以下内容
```css
/* 文章正文所有段落首行缩进 */
.post-content p {
  text-indent: 2em;
}

/* 排除不需要缩进的元素 */
.post-content blockquote p,
.post-content li p,
.post-content table p,
.post-content pre p,
.post-content .highlight p {
  text-indent: 0;
}
```

**问题六：写文章时用的是中文全角标点，用电脑浏览器打开看到的是英文半角标点。**

解决办法：打开source/css/custom.css，在后面写入以下代码

```css
/* ============================================================
   中文排版修复：只覆盖文本内容，不碰图标
   ============================================================ */

/* 1. 正文区域使用中文黑体，覆盖主题默认的西文字体栈 */
.post-content,
article,
.markdown-body,
.content,
.page-content,
.site-main {
  font-family: "Noto Sans SC",
               "PingFang SC",
               "Hiragino Sans GB",
               "Microsoft YaHei",
               sans-serif !important;
}

/* 2. 标题区域同理 */
:lang(zh) h1,
:lang(zh) h2,
:lang(zh) h3,
:lang(zh) h4,
:lang(zh) h5,
:lang(zh) h6 {
  font-family: "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif !important;
}

/* ============================================================
   图标字体修复：明确指定 Font Awesome 6 字体名称
   （不能写 inherit，必须写死图标字体的名字）
   ============================================================ */

/* 所有 Font Awesome 图标元素 */
.fas, .far, .fab, .fal, .fa {
  font-family: "Font Awesome 6 Free" !important;
}

/* Solid 风格（实心图标）：需要加粗才能出字形 */
.fas {
  font-weight: 900 !important;
}

/* Regular 风格（线框图标）：正常字重 */
.far {
  font-weight: 400 !important;
}

/* Brands 风格（品牌 logo）：独立字体族 */
.fab {
  font-family: "Font Awesome 6 Brands" !important;
  font-weight: 400 !important;
}

/* 兜底：匹配所有包含 fa- 的 class（如 fa-home、fa-archive） */
[class*="fa-"] {
  font-family: "Font Awesome 6 Free" !important;
  font-weight: 900 !important;
}

/* 如果主题用了 <i class="iconfont"> 这类自定图标 */
.iconfont,
[class*="iconfont"] {
  font-family: "iconfont" !important;
}

/* ============================================================
   关闭可能影响标点宽度的排版特性
   ============================================================ */

* {
  text-spacing-trim: normal !important;
  font-feature-settings: normal !important;
  font-variant-ligatures: normal !important;
}

/* ============================================================
   代码块保持等宽字体
   ============================================================ */

pre, code, kbd, samp {
  font-family: Consolas, Monaco, "Courier New", monospace !important;
}
```

**问题七：字体偏小，页面过宽。**

解决办法：打开source/css/custom.css，在后面写入以下代码

```css
/* ============================================================
   Keep 主题自定义样式
   作用：覆盖主题默认CSS变量，优化字体、排版与视觉效果
   修改时间：2026-10-20
   ============================================================ */
:root {
  /* 全局基础字体大小 */
  --base-font-size: 18px;     /* 推荐范围：14px ~ 18px */
  /* 全局基础行高 */      
  --base-line-height: 29px;     /* 推荐范围：1.5 ~ 1.8 倍字体大小 */
  /* 内容区域的最大像素宽度 */
  --page-content-max-width: 850px;     /* 纯文字博客推荐 800px ~ 900px */
  /* 隐藏文章内容页面的文章修改时间 */
  --post-update-datetime: none;     /* 可选值：flex（显示）、none（隐藏） */
}
```
