9月27日晚上，我决定用 Hexo + GitHub Pages 创建个人博客。我让豆包提供了一份《 Hexo + GitHub Pages 搭建个人博客完整教程》，一边看教程，一边操作。因为下载速度太慢，临睡前我只安装了 Node.js 和 Git。

9月28日早上，我利用工作间隙注册了 GitHub 账号并创建站点仓库，安装了 Hexo，最后把网站部署到 GitHub Pages。中午，我让豆包给我推荐了5款适合新手的 Hexo 主题，我看了介绍之后选择了ils，因为 I Like Simple。安装了ils 之后，我发现首页的文章只显示摘要，点击文章标题和阅读全文都会跳转到空页面，但在 source\\_posts 里有文章对应的 md 文件。我问豆包该如何设置才能看到整篇文章，我按它的提示操作也没有解决问题。我正准备放弃努力时，无意中发现使用 hexo deploy 命令后，出现了一些报错提示。豆包告诉我这是主题依赖的字数统计插件缺失导致的模板渲染报错，关闭字数统计功能就能解决。我试过之后，惊喜地发现一直困扰我的问题也解决了。做完这一切，一天即将过去。写下这段文字记录这全情投入的一天。

10月3日下午，回顾了这几天研究 ils 主题的经过，主要解决了三个问题：1.首页只显示文章摘要，点击阅读全文会跳转到空页面。2.博客文章没有首行缩进。3.新建的分类页和标签页点开后是空页面。前两个问题是豆包帮我解决的，第三个问题是在千问的协助下解决的。晚上十点半，安装新主题 keep 并开始设置，到一点钟，基本设置好，花了两个半小时，出乎我的意料。

10月5日上午，在千问的帮助下，通过在 Keep 主题中注入自定义的 CSS 解决博客文章没有首行缩进的问题。目前，自定义配置多个作者标识还没解决。

10月6日上午，把昨天晚上用 workbuddy 转换的 svg 图标上传到博客，替换原来的 png 图标，虽然没有原生 svg 图标小，但体积也只有原先图标的三分之一。

10月7日晚上九点，在豆包的指导下，我开始把博客源码推送到 GitHub 仓库的 main 分支，到凌晨一点半才成功，真是不容易。
